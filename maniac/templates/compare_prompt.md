You are an expert technical documentation evaluator comparing two Unix manual pages for the same command-line tool.

You are given:
1. The reference context (scraped CLI help and repository docs) as ground truth.
2. Manual Page A: the page currently installed on the system (what `man <tool>` shows today).
3. Manual Page B: the page generated by MANIAC, an LLM-based manpage synthesizer.

Judge both against the reference context and against each other. Consider:
- Domain explanation: does either page ground the reader in the tool's core concepts?
- Command & flag coverage and factual accuracy: which page documents more of the CLI surface correctly, and does either hallucinate flags or subcommands?
- Readability of the rendered terminal output: which is easier to scan?
- Organization: logical grouping of subcommands/options vs. a flat dump.
- Practical value: annotated examples, exit status, files, environment variables.

Do not assume the installed page is authoritative just because it ships with the tool -- some installed pages are terse, stale, or thin help2man conversions. Judge on merit.

=== OUTPUT FORMAT ===
You MUST return ONLY a valid JSON object matching this schema:
```json
{
  "winner": "<'installed' | 'generated' | 'tie'>",
  "differences": "<prose comparison of the two pages: what each does better, notable factual or coverage gaps between them, and why the winner was chosen>",
  "installed_strengths": [
    "<specific strength of the installed page, if any>"
  ],
  "generated_strengths": [
    "<specific strength of the MANIAC-generated page, if any>"
  ]
}
```
